### 四、语言切换面结论

- **形态**：vitepress locale 路由（`/` 英文、`/zh/` 中文）+ README 双语文件对。两者皆为受规形态。
- **线上契约**：`/` → `(200, en-US, CJK 0)`；`/zh/` → `(200, zh-CN, CJK 48)`。双路由均活，语言标签正确，中文页确有中文。
