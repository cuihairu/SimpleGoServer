# SimpleGoServer 面试题

设计一个高性能，可扩展的非阻塞网络通信模型，能够处理大量并发连接和数据传输。模型应该支持TCP协议或自定义基于TCP的协议。需要合理处理网络连接的生命周期管理，异常情况以及资源优化。

## 要求:

### 1. 模型架构：
  - 设计一个事件驱动的服务器模型，能够异步处理客户端连接和数据交换。
  - 使用go语言的goroutines和channels来实现并发性和非阻塞I/O操作。
  - 服务器应支持多核处理，并能有效利用所有可能的CPU核心。


### 2. 协议支持:
   - 支持TCP协议
   - 对于TCP连接，需要处理连接的建立，数据传输和连接的优雅关闭
   - 支持自定义协议

### 3. 通信格式:
   - 设计一个自定义应用协议，用于封装和解析传输数据。
   - 支持JSON作为数据交换格式，以便客户端和服务器能够传递结构化的数据。

### 4. 错误处理和恢复:
   - 实现完善的错误处理机制，包括网络错误，协议错误和应用程序错误。
   - 在发送致命错误是，服务器应能够优雅关闭现有联机，并记录错误日志以边问题追踪。

### 5. 性能测试和恢复:
   - 编写性能测试用例，模拟大量并发连接和数据传输，验证服务器的性能和扩展性。 

### 6. 可维护性和可扩展性:
   - 设计清晰的代码结构和模块划分，以便代码的维护和扩展。
   - 提供适当的配置选项，以支持不同的部署环境和性能要求。

### 7. 文档和测试
  - 编写单元测试和集成测试，确保代码的质量和功能的正确性。

### 9. 负载均衡:
  - 实现一种自适应的负载均衡策略，以动态分配客户段连接到不同的服务器实例。

### 10. 自定义协议:
  - 实习一个自定义的协议支持更多的功能。支持请求/响应模式、发布、订阅模式或流式传输。
